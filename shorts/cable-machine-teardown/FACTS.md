# Cable machine (2:1): facts and sources

Numbers come from search-result text of the pages below. Worked figures are labelled as calculations.

| Claim in script / on screen | Source(s) | Notes |
|---|---|---|
| Weight plates ride on guide rods; a selector pin picks how many plates the cable lifts | Common selectorized-stack design (MuscleSquad "Gym equipment 101: Cable machines"; Rep Fitness single vs dual stack guide) | Model uses 10 plates in 10 lb steps; plate size is illustrative, real stacks vary (10/15/20 lb steps). |
| 1:1 ratio: stack number = handle resistance (e.g. 160 lb on the stack = 160 lb) | Fringe Sport "Best functional trainers"; MuscleSquad "1:1 and 2:1 cable machines" | |
| 2:1: the cable runs through a movable pulley; resistance is about half the stack (100 lb → ~50 lb) and cable travel doubles | Fringe Sport "Cable machine pulley ratio 2:1 explained"; Rep Fitness "What do cable ratios mean"; Skelcore "What does 2:1 weight ratio mean"; US patent 7601105 (cable crossover, 150 lb stack → 75 lb at handle) | Two strands support the moving pulley → each strand carries W/2 (ideal). |
| 4:1: a quarter of the force, four times the travel | Skelcore "Why cable ratio matters: 2:1 vs 4:1 vs 6:1" | |
| Force × distance stays the same (work conserved, ideal) | Wikipedia "Block and tackle" (ideal mechanical advantage = number of supporting rope sections) | 50 lb × 1 ft = 25 lb × 2 ft. |
| Each pulley loses a few percent to friction: "≈3–5% per ball-bearing pulley" | Wikipedia "Block and tackle": friction factor ≈1.04 per roller-bearing sheave (1.09 plain bearing); equipment guides quote sealed ball-bearing sheaves at 94–97% efficiency | Model uses 5% loss (factor 1.05) per pulley, the conservative end. |
| Friction adds to the load when lifting, subtracts when lowering | Physics of Coulomb friction opposing motion; patent US 12070643 notes cable/pulley friction reduces force felt during the release phase | |
| "≈25 lb in your hands, closer to 30 pulling, 20 letting go" | **Calculation**: 4 pulleys in the modelled path (movable + 3 fixed), factor 1.05 each → 1.05⁴ = 1.216. Pulling: 25 × 1.216 ≈ 30.4 lb. Lowering: 25 / 1.216 ≈ 20.6 lb. | Rounded on screen. Ignores rod/bushing friction and the head-plate/stem weight. |
| Cable: 1/8″ bare 7×19 steel wire rope, 3/16″ with nylon jacket, ~2,000 lb breaking strength; nylon-coated rope is used for gym cables | Sportsmith "Exerflex Pro cable 3/16 black nylon coating" (1/8″ bare = 3/16″ coated); Stage Lighting Store / Fehr 1/8–3/16″ 7×19 nylon-coated (2,000 lb, "ideal for … gym equipment cables") | |
| Cable stretch "about a millimeter here" / "≈0.02% at 25 lb" | **Calculation** with Lexco / Loos & Co. elastic-stretch formula E% = W·G/D², G = 0.0000140 (galvanized 7×19): 25 × 0.000014 / 0.125² = 0.022%. Over an assumed ~5 m cable run → ≈1.1 mm. | Cable length is an assumption for a single station. |
| 1 ft of stack travel ↔ 2 ft of handle travel | Follows from 2:1 geometry | Model: stack lift 0.3048 m. |
