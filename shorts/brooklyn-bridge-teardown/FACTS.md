# Brooklyn Bridge: facts and sources

Note: facts come from web search-result text of the pages below (direct page fetches not used). Where sources disagree, the script uses the safest wording.

| Claim in script / on screen | Source(s) | Notes |
|---|---|---|
| Longest suspension bridge in the world when it opened; main span ~1,595 ft | Structurae "Brooklyn Bridge"; Wikipedia "Brooklyn Bridge"; ASCE Historic Landmark page | 1,595.5 ft (486.3 m). |
| Work began 1870 | todayinhistory.blog "January 3, 1870 Mr. Roebling's Bridge"; Wikipedia | Sources give Jan 2 or Jan 3, 1870 for breaking ground; VO says only "1870". |
| John A. Roebling designed it and died in 1869 (tetanus after a foot injury); son Washington took over | History.com "Brooklyn Bridge"; Engineers Ireland "Brooklyn Bridge construction: turning tragedy into triumph" | |
| Caissons: giant upside-down timber boxes sunk into the riverbed; men dug inside in compressed air | STRUCTURE magazine "Brooklyn Bridge, Part 2"; Kids Discover "How the Brooklyn Bridge was built" | Brooklyn caisson 168 × 102 ft (Manhattan 172 × 102 ft) per Wikipedia/STRUCTURE. Shown: "168 × 102 ft". |
| Brooklyn caisson 44 ft, Manhattan 78 ft | History.com; STRUCTURE "Brooklyn Bridge, Part 2" (44½ ft and 78 ft 6 in) | Rounded to 44 / 78. |
| Brooklyn caisson fire (Dec 1870); filled with concrete March 1871; Manhattan caisson filled July 1872 | STRUCTURE "Brooklyn Bridge, Part 2"; HMdb "Two Bridges" marker | Not in VO; background. |
| Workers got caisson disease ("the bends"), some fatal; Washington Roebling left partially paralyzed / bedridden | History.com; STRUCTURE "Brooklyn Bridge, Part 2"; history.com "Brooklyn Bridge construction deaths" | Sources differ on severity; card says "crippled by the bends · bedridden". |
| Emily Roebling relayed his orders and effectively ran the job | Wikipedia; The B1M "The Woman Who Built the Brooklyn Bridge" | |
| Granite towers, 276 ft | ASCE (276.5 ft); Wikipedia mirrors (some list 272 ft) | Towers: granite and limestone with Rosendale cement; "granite towers" is the common description. Two pointed (Gothic) arches. |
| Anchorages: ~60,000 tons each, chains inside to anchor plates (23 tons) | Wikipedia (60,000 tons each, solid except cable passages); Historical Marker Project "How the Bridge Was Built" (23-ton anchor plates) | |
| Cable spinning 1877–1878, steel wire, wheels carried wire across | AISC Modern Steel Construction (June 2011) "Brooklyn Bridge"; nycsubway.org "Chapter 04: Bridges to Brooklyn"; untappedcities (1878 cable incident) | Start Feb or June 1877 depending on source; last wire Oct 5, 1878. |
| Four cables, 19 strands each (278 wires per strand), ~15¾ in diameter | nycsubway.org Ch. 04; Engineering Wonders of the World; Wikipedia | AISC's 5,434-wire total not used (19 × 278 = 5,282). |
| Vertical suspenders + diagonal stays carry the deck (hybrid suspension/cable-stayed); stiffening trusses | Wikipedia; Structurae; ASCE | ~400 stays. |
| Opened May 24, 1883; Emily Roebling first to cross | OUP blog "The Brooklyn Bridge opens" (2012); todayinhistory.blog "May 24, 1883 First Across"; Wikipedia | |
| ~150,300 people crossed on opening day (VO: "about 150,000") | Wikipedia; historycentral.com | |
| Trains crossed until 1944 | Wikipedia "Brooklyn Bridge" (elevated trains ended 1944; trolleys to 1950) | From model knowledge of Wikipedia; not re-fetched this session. Card: "1883–1944 trains ran on the bridge". |
| Two-way protected bike lane opened September 2021, taking one car lane | Greenpointers (2021); NYC DOT | |
| Rehabilitations: Steinman 1948–54; NYCDOT program from 2010 | equipmentworld.com "Working Work of Art"; NY Senate resolution; Structurae | Not in VO. |
