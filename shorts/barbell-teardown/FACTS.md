# Olympic barbell: facts and sources

| Claim in script / on screen | Source(s) | Notes |
|---|---|---|
| Men's competition bar: 20 kg, 2.2 m (2200 mm) long | IWF equipment page (iwf.net/weightlifting_/equipment) confirms 20 kg men's bar; Torokhtiy "Olympic barbell dimensions" (citing IWF Technical Rules): 2200 mm, 20 kg | |
| Shaft Ø 28 mm, sleeve Ø 50 mm | Torokhtiy guide (IWF Technical Rules); Strength Shop IWF men's spec listing (shaft 28 mm, sleeve 50 mm, overall 2200 mm); Eleiko IWF competition bar product sheet | Loadable sleeve ~415 mm, shaft between collars ~1310 mm (retailer specs) used for model proportions only. |
| "Alloy steel" shaft | Texas Power Bars / Wolverson barbell guides; 4140 chromoly listed by several makers | Exact alloy varies by maker; kept generic. |
| ~190,000 PSI tensile strength; ≈ 1,310 MPa | Garage Gym Reviews (American Barbell bar reviews): "around 190k is ideal", >150k PSI minimum; American Barbell spec sheets (190K PSI shaft); Wolverson guide: quality bars 190,000–215,000 PSI | 190,000 psi × 6.895 kPa/psi = 1,310 MPa. Vendors are inconsistent about tensile vs. yield; VO says "rated around". |
| Tensile = stress that tears it apart; yield = point past which it bends for good; below yield it springs back | Standard materials definitions; Texas Power Bars "Whip vs flex vs bend"; Fringe Sport "Why do some barbells bend" (yield = permanent bend) | Stress–strain graphic is a schematic shape, not test data. |
| Knurl: crossed grooves → diamond points that grip | Diamond knurling (crossed helical grooves) — general machining definition; retailer listings describe "diamond-cut" knurl | Pitch on the model is schematic. |
| Grip marks 910 mm apart (IWF) | Fringe Sport "Knurl marks explained"; Gym-Mikolo "Understanding barbell lines" (IWF 910 mm, IPF 810 mm) | |
| Centre knurl on men's bars, helps hold the bar on the shoulders/back | Rogue IWF bar w/ centre knurl listing; Gym-Mikolo guide; women's bars omit it | |
| Sleeves spin on bronze bushings or needle bearings; needles spin faster | Strength Shop "Bushings vs needle bearings"; Eleiko "Understanding barbell rotation"; American Barbell "Understanding the Olympic needle bearing bar" | |
| Spin matters in snatch/clean: bar turns over around the wrists while sleeves/plates don't have to rotate | Eleiko "Understanding barbell rotation"; Strength Shop article | |
| Snap rings retain the sleeves, end caps, collars clamp plates | Rogue "Barbell components"; Rep Fitness "Different barbell sleeves" | |
| Whip: bar flexes under heavy load, stores and releases energy; lifters time the drive to the rebound | Acoustical Society of America #ASA190 / Newswise "Whip it good" (J. Langlois, Penn State): flexural bending lifters feel and use; Texas Power Bars "Whip vs flex vs bend" | Deflection in the animation is exaggerated (stated on screen). |
| 25 kg bumper plates: Ø 450 mm, red | IWF colour code (red = 25 kg), standard 450 mm plate diameter | Visual only; no plate weights stated in VO. |
