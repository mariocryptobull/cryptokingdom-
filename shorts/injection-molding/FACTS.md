# FACTS — How Plastic Parts Are Made (Injection Molding)

| Claim in film | Source | Note |
|---|---|---|
| The machine has two principal components: an injection unit and a clamping unit | ME240 lecture "Polymer Processing I – Injection Molding" (Inacio, Lehigh) ; Groover, *Fundamentals of Modern Manufacturing* 4e, §13.6 | "Two principal components: 1. Injection unit 2. Clamping unit" |
| The barrel is fed from a hopper of plastic pellets | same lecture | "barrel fed from one end by hopper containing supply of plastic pellets" |
| The reciprocating screw has two jobs: it rotates to mix/heat, then acts as a ram to inject | same lecture | "1. Rotates for mixing and heating polymer 2. Acts as a ram (i.e., plunger) to inject molten plastic into mold" |
| Heater bands heat the barrel | https://dozuki.umd.edu/Wiki/Injection_molding_process ; https://resources.skill-lync.com/courses/injection-molding-fundamentals/machine | |
| Flow path: nozzle → sprue → runners → gate → cavity | same lecture ("The Runner System … from the machine's sprue to the mold cavity gates") ; https://maketime.io/resources/injection-mold-components/ | |
| Cooling is usually the longest step of the cycle | https://www.yizumi.com/en/news/product/IMM/how-to-minimize-cycle-time-in-injection-molding ; https://www.moldall.com/demystifying-injection-molding-cooling-time-a-zetarmold-guide-to-efficiency-and-quality | Industry sources; exact share varies (thin-wall parts can be lower), so the film says "usually" |
| Ejector pins push the part out when the mold opens | https://dozuki.umd.edu/Wiki/Injection_molding_process | |
| Typical cycle time ~10–30 s (longer for large parts) | same lecture ; Groover §13.6 | "Typical cycle time ~10 to 30 sec, but cycles of one minute or more are not uncommon" |
| A mold may contain multiple cavities → several parts per cycle | same lecture | "Mold may contain multiple cavities, so multiple moldings are produced each cycle" |

The machine and 4-cavity cap mold are an illustrative model. The products in the opening (phone case, bottle cap, keycap) are generic examples of common injection-molded parts.
