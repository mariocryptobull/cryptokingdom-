# Tunnel boring machine: facts and sources

Direct page fetches are blocked on this network; facts come from search-result text of the pages below.

| Claim in script | Source(s) | Notes |
|---|---|---|
| TBMs dig tunnels with little surface disruption (vs. cut-and-cover) | Trenchlesspedia "How Tunnel Boring Machines Work"; railwaynews.net "What is a TBM? The 'Mole'" | Framed as "without tearing up the city". |
| Cutterhead with disc cutters; discs create compressive stress fractures so rock chips away | Wikipedia "Tunnel boring machine" (mirror): "disc cutters create compressive stress fractures in the rock, causing it to chip away" | "Few times a minute": hard-rock cutterheads typically turn a few to ~10 rpm (general industry figure; kept vague on purpose). |
| Soft ground: face held up by pressurized soil (EPB) or slurry | Wikipedia TBM article: EPB uses excavated material under pressure, removed by screw conveyor; slurry shields use pressurized bentonite slurry, spoil pumped out | |
| Shield keeps the tunnel open while crews work inside | Trenchlesspedia; Wikipedia TBM (single/double shield) | |
| Muck carried back by screw conveyor, then belt conveyor out of the tunnel | Wikipedia TBM: screw conveyor "carries excavated rocks and earth from cutting face to the rear"; belt conveyors/muck cars to the portal | |
| Segment erector sets precast concrete segments into rings: lining built as it goes | Wikipedia TBM: "segment erector robot installs pre-cast reinforced concrete segments to form the permanent tunnel lining" | |
| Thrust cylinders push off the last ring; adjusting them steers | Wikipedia TBM ("thrust cylinders to advance forward by pushing off against concrete segments"); Trenchlesspedia (steer by adjusting the ring of hydraulic cylinders) | |
| Cycle: cut → muck → ring → push, around the clock | Synthesis of the above; 24-h operation is standard on TBM drives | |
| Second Avenue Subway TBM ("Adi"): 450 ft long, 485 tons, ~22 ft cutterhead, ~7,789 ft mined, ~60 ft/day average | MTA via Jalopnik "The 485-Ton Machine That Chewed Through Manhattan"; Untapped Cities; Tunnelling Journal | Built by Robbins, launched May 2010. Some sources give 7.2 m (23.6 ft) diameter. |
| Context (not in VO): record advance ~70–100 m/day; typical tens of m/day | TunnelTalk (Cabrera), Water Power Magazine (Sunkoshi Marin 72.6 m/day) | "Quick" is relative: faster and safer than drill-and-blast in many grounds, not fast in absolute terms. |
