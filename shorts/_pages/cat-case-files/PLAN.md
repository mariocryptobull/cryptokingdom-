# Cat Case Files — second page (true crime / heists), saved for later

Status: **parked**. Separate account from the engineering explainer page. Decided 2026-11-04.

## Concept
Short true-crime stories told with the PS1 mascot cat as a detective. Built on the PS1 house style (`shorts/_styles/ps1-retro/STYLE.md`); reference kit: `shorts/turbo-ps1/`, mascot variant: `shorts/jacked-cat-ps1/`.

- Series frame: "CASE FILE #00X" title card → evidence-board beats → "CASE CLOSED" / "STILL UNSOLVED" stamp.
- The cat reacts to the scheme (impressed, suspicious, head-spin at the twist), never to anyone's suffering.
- 60–65 s, hook in the first 1–2 s, short title card (~1 s), sources in FACTS.md and the caption.

## Since it's its own page
- Can cover the full range of true crime, not only heists, but murder cases need a more serious tone: slower music, fewer meme beats, and the cat as quiet narrator-detective, not the comic relief.
- New name, handle, bio and pinned intro video; don't cross-post with the engineering page.

## Rules for every case
1. Public record only: convictions, court records, reputable reporting. Each claim goes in FACTS.md.
2. No gore; no child victims; avoid recent cases and private living people.
3. Unsolved cases = presented as theories, never accusations against named people.
4. Respect victims: no jokes at their expense.
5. Check YouTube and TikTok rules on violent content before posting murder cases (age limits and ad limits).
